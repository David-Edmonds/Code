# David AI Build Lab

A public-safe command center for planning, building, reviewing, and shipping David Edmonds's AI-assisted software and automation projects.

This repository is **not** a place for passwords, private family information, client data, medical information, immigration records, banking details, or confidential source files. It contains reusable plans, prompts, checklists, issue templates, and public project status only.

## Operating rule

Use the smallest capable tool:

1. ChatGPT for decisions, research, briefs, and review
2. Codex for repository changes, tests, and pull requests
3. GitHub for code, issues, release history, and project truth
4. An existing connected app or official API for external actions
5. Custom infrastructure only after a real requirement exists

## Standard workflow

1. Create or update a project brief.
2. Open one issue for one outcome.
3. Ask Codex to inspect before changing code.
4. Work on a branch and open a pull request.
5. Run automated checks and perform a truth/privacy review.
6. Merge and publish only after verification.
7. Record what changed and the next highest-value task.

See `CURRENT_CONTEXT.md`, `DECISIONS.md`, `AGENTS.md`, `BACKLOG.md`, and `templates/` before starting a build.
