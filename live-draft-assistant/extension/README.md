# Chrome Side-Panel Widget

1. Start the local app with `run_windows.bat`.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose this `extension` folder.
6. Pin **David's Live Draft Widget**.
7. Open the Yahoo draft room and click the extension icon.

The side panel refreshes every three seconds and uses the local API at `http://127.0.0.1:8765`.
