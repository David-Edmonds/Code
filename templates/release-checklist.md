# Release Checklist

- [ ] Acceptance criteria are met
- [ ] Lint, type checks, tests, and build pass
- [ ] Desktop and mobile layouts were reviewed
- [ ] Links, forms, and downloads work
- [ ] No secrets or confidential data were added
- [ ] Public claims are supported and correctly labeled
- [ ] Error states and empty states are understandable
- [ ] Permissions and paid-service changes were documented
- [ ] Deployment completed or the remaining manual step is explicit
- [ ] Changelog/project status was updated
